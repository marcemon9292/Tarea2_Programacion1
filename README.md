
# Tarea 2 - Principios de Programacion I

## Descripcion del proyecto

Este proyecto corresponde a la Tarea 2 del curso Principios de Programacion I de la Universidad CENFOTEC.

Contiene cuatro ejercicios de programacion en Python y seis laboratorios realizados a partir de los temas y ejemplos trabajados en clase.

## Objetivos

- Aplicar estructuras condicionales y repetitivas.
- Utilizar contadores y acumuladores.
- Implementar validaciones de datos.
- Trabajar con funciones y colecciones.
- Documentar y comprobar el funcionamiento de los programas.

## Funcionalidades

### Ejercicios principales

1. Control de temperatura: simula el aumento de temperatura hasta alcanzar un objetivo.
2. Consumo de agua: registra y analiza el consumo durante siete dias.
3. Estacionamiento: administra entradas, salidas y cobros de vehiculos.
4. Expedicion: controla el consumo de agua y alimentos durante una cantidad determinada de jornadas.

### Laboratorios de clase

1. Menu: cajero automatico.
2. Condicional multiple: calculo de descuentos.
3. Ciclos while: contador de numeros.
4. Ciclos for: sumatoria de una lista.
5. Menu con while True: lista de compras.
6. Colecciones: operaciones con listas.

## Requisitos previos

- Tener Python 3 instalado.
- Tener Visual Studio Code u otro editor compatible con Python.

## Instrucciones de ejecucion

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Seleccionar el archivo .py que se desea ejecutar.
4. Ejecutar el programa utilizando Python.
5. Seguir las instrucciones que aparecen en la terminal.

## Ejecución desde la terminal

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir una terminal.
4. Ejecutar el programa deseado con Python.

Ejemplo:

python Ejercicios/ejercicio1_temperatura.py

Los ejercicios se ejecutan de forma independiente y solicitan
los datos necesarios mediante la consola.
